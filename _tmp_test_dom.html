M.Sc. project — Postgraduate

An Approach against Detecting Co-residence using Network Probes in Cloud

Cyber security research on multi-tenant cloud infrastructure. An attacker can work out which virtual machines share a physical host by timing network probes, and that co-residence becomes the stepping stone to side-channel attacks. This project examines those probing techniques and proposes a defensive approach that obscures the network signals they rely on.
